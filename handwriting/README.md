# Five personal handwriting images

Save one digit per PNG here:

- `digit_5.png`: a handwritten 5
- `digit_7.png`: a handwritten 7

Use Paint: approximately 280 x 280 pixels, white background, black strokes about 15-20 pixels wide, and a clear margin. Save as PNG, not a screenshot. Do not resize to 28 x 28 yourself. Keep the first attempts, including mistakes.

Run Sections 1.8 and 1.9 in the homework notebook, then save with Ctrl+S. If drawing different digits, change `HANDWRITING_FILES` to match their filenames and true labels. No images are used for training.
